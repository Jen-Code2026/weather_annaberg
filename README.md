That said: what's this about?

The project

I'm creating a weather program which not only shows the local weather of a very small town in Lower Austria, 
but also calculates if the weather will affect whether the lift can run safely.

I want to calculate the most probable weather for the region to solve the problem that we have to check several 
weather forecasts a day to determine which seems most likely. Because all of them are very widely different, 
and all of them are more often wrong than not.

Why?

To learn Python while programming something useful. Yes, for the broad majority of people it will be completely 
useless, but a handful of people check the weather multiple times daily to see if it's safe to let the lift run.
